## 1. 소개
실제 경기 데이터는 골, 도움, 패스 성공률 등 경기에서 나타난 기록을 제공하고, Football Manager(FM) 데이터는 선수의 능력과 특성을 수치로 보여줍니다.

FMRS는 공통 식별자가 없는 두 선수 데이터셋을 자동으로 연결해 실제 경기 기록과 FM 능력치를 함께 조회할 수 있는 서비스입니다.

사용자는 이름, 소속팀, 국적, FM 능력치 등의 조건으로 선수를 검색하고, 상세 조회를 통해 해당 선수의 실제 경기 스탯과 매핑된 FM 능력치를 함께 확인할 수 있습니다.

## 3. 성과

### 검색 API 응답 시간 98% 단축 — p95 2,801ms → 38.4ms
>20만 건 규모에서 k6로 100 RPS 부하를 가했을 때 검색 API의 p95 응답 시간이 2,801ms까지 증가했습니다.  
>실행 계획으로 병목을 확인하고, 인덱스 튜닝과 스키마 개선 두 단계를 통해 p95를 38.4ms까지 단축했습니다.

### 5대 리그 매핑률 72.1% → 82.8%
>두 데이터셋에 공통 식별자가 없고 이름 표기 방식도 달라, 단계별 매핑 전략을 적용해 5대 리그 매핑률을 72.1%에서 82.8%로 높였습니다.  
>전체 매핑률은 FM 데이터에 없는 선수가 분모에 포함돼 100% 도달이 불가능한 지표라, 실제 조회가 집중되는 5대 리그로 분모를 재정의했습니다.

### 매핑 후보 대량 유실 발견 — 429명 → 7,713명
>단위 테스트는 전부 통과했지만, 실제 실행 결과가 기대치에 크게 미달했습니다.  
>DB와 애플리케이션의 문자열 비교 기준이 달라 후보가 유실되고 있었고,
>후보 키 정규화와 회귀 테스트로 해결했습니다.
