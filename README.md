## 1. 소개
실제 경기 데이터는 골, 도움, 패스 성공률 등 경기에서 나타난 기록을 제공하고, Football Manager(FM) 데이터는 선수의 능력과 특성을 수치로 보여줍니다.

FMRS는 공통 식별자가 없는 두 선수 데이터셋을 자동으로 연결해 실제 경기 기록과 FM 능력치를 함께 조회할 수 있는 서비스입니다.

사용자는 이름, 소속팀, 국적, FM 능력치 등의 조건으로 선수를 검색하고, 상세 조회를 통해 해당 선수의 실제 경기 스탯과 매핑된 FM 능력치를 함께 확인할 수 있습니다.  

또한 인증된 사용자는 특정 선수에 대해 댓글을 작성 및 조회할 수 있으며, 필요에 따라 댓글을 삭제할 수 있습니다.

## 3. 성과

### 검색 API 응답 시간 98% 단축 — p95 2,801ms → 38.4ms
>20만 건 규모에서 k6로 100 RPS 부하를 가했을 때 검색 API의 p95 응답 시간이 2,801ms까지 증가했습니다.  
>실행 계획으로 병목을 확인하고, 인덱스 튜닝과 스키마 개선을 단계적으로 적용해 p95를 38.4ms까지 단축했습니다.

### 5대 리그 매핑률 72.1% → 82.8%
>두 데이터셋의 교집합이 전체의 55%뿐이라 "전체 대비 매핑률"은 애초에 100% 도달이 불가능한 지표임을 발견했습니다.
>실제 조회가 집중되는 5대 리그 선수 기준으로 분모를 재정의하고, 단계별 매핑 전략을 적용해 5대 리그 매핑률을 72.1%에서 82.8%로 높였습니다.

### 매핑 후보 대량 유실 발견 — 429명 → 7,713명
>단위 테스트는 통과했지만, 매핑 조건을 만족한 후보가 실제 실행에서는 누락됐습니다.  
>DB는 대소문자를 구분하지 않는 반면 Java의 후보 키는 이를 구분하고 있어, 키 정규화와 회귀 테스트를 적용했습니다.
