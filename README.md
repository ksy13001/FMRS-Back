## 1. 소개
공통 식별자가 없는 두 개의 축구 선수 데이터를 자동으로 연결해, 게임 내 능력치와 실제 성적을 함께 조회하는 서비스입니다.

사용자는 이름, 소속팀, 국적, FM 능력치 등의 조건으로 선수를 검색하고, 상세 조회를 통해 해당 선수의 실제 경기 스탯과 매핑된 FM 능력치를 함께 확인할 수 있습니다.  

또한 인증된 사용자는 특정 선수에 대해 댓글을 작성 및 조회할 수 있으며, 필요에 따라 댓글을 삭제할 수 있습니다.

## 3. 성과

### 검색 API 응답 시간 98% 단축 — p95 2,801ms → 38.4ms
>20만 건 규모에서 k6로 100 RPS 부하를 가했을 때 검색 API의 p95 응답 시간이 2,801ms까지 증가했습니다.  
>실행 계획으로 병목을 확인하고, 인덱스 튜닝과 스키마 개선을 단계적으로 적용해 p95를 38.4ms까지 단축했습니다.

### 5대 리그 매핑률 72.1% → 82.8%
>두 데이터 소스에 공통 식별자가 없고 이름 표기 방식도 달랐습니다.
>정밀도가 높은 전략부터 단계적으로 적용하고, 애매한 후보는 자동 확정하지 않고 별도 상태로 분리했습니다.

### 매핑 후보 대량 유실 발견 — 매칭 대상 429명 → 7,713명
>단위 테스트는 통과했지만, 생년월일과 국적이 같고 이름 토큰이 일치하는 후보가 실제 실행에서는 누락됐습니다.  
>DB는 대소문자를 구분하지 않는 반면 Java의 후보 키는 이를 구분하고 있어, 키 정규화와 회귀 테스트를 적용했습니다.
